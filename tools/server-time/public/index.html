3 · 클릭 도달 시각 측정

아래 버튼을 누르면 그 순간의 서버 시각과, 그 클릭 신호가 서버에 도달하는 시각을 계산합니다. 동시에 실제 요청을 한 번 보내 응답 Date로 검증합니다. (스페이스바로도 가능)

4 · 목표 시각 카운트다운

신청 시작 시각을 넣으면, 신호가 정각에 서버에 닿도록 먼저 눌러야 할 시각을 계산해 카운트다운합니다.

읽고 쓰기

  • 서버 시각은 Date 헤더(초 단위)를 수십 번의 요청으로 구간 교차시켜 밀리초까지 좁힌 값입니다. 표시된 ± 가 오차 한계입니다.
  • 편도 지연은 최소 왕복시간의 절반입니다. 목표 시각 편도 지연만큼 전에 눌러야 신호가 정각에 도착합니다.
  • 사이트가 CDN·로드밸런서 뒤에 있으면 Date는 그 앞단 장비의 시각입니다. 보통 NTP로 맞춰져 있지만, 실제 접수 서버와 몇 ms 차이가 날 수 있습니다.
  • 브라우저에서 실제 버튼을 누를 때는 클릭 처리·JS 실행·TLS 재개 등으로 여기서 잰 값보다 몇 ms가 더 붙습니다. 여유 값으로 보정하세요.
